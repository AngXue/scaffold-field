| --- | --- |

| 桌面材料表和导出 | 屋顶单跨 CSV 的定尺钢管、十字扣、底座和钢笆数量与手算一致，改成 3 层后对接扣为 4 个。正面与花园的 CSV 为 294 个十字扣、64 片钢笆、9 根底座、41.40 m²，0.7 项目同步保留测算结果。 |
| 错误定位和草图 | 窄顶面、跨台阶、扫地杆冲突、穿屋和独立架段重叠均能定位，材料 CSV 被拦截。窄顶面还能保存草图，修正后可再次查看材料。 |
| 标高、叠放和存档 | 恰好落在全局层标高时取下一层。父体块改高后撤销及保存重开均保留预期层数和标高。平地旧图读档后可导出 OA 0.6，平地闭环周长为 14.40 m。 |
| 左侧居中走廊 | 重画两笔贴墙架段，验证 0.30 m 距墙、走廊顶两对立柱、第一层两处无横向端栏杆、第二层起同层接通。全局目标从 5 层改为 4 层后，已有左侧架段重算为 4／3／4 层；恢复 5 层时 CSV 对应 109 片钢笆及 14 根底座。保存重开和 0.7 JSON 保留两笔。 |
| Chrome 模拟触摸 1152 × 680 和 720 × 1110 | 单指重画左侧墙线可吸附并自动跨过走廊。双指取消未提交的笔画或移动。绘图、三维检查和材料表通过横竖屏视口检查。 |

`npm test` 通过 142 项，其中包含走廊柱位、纵距缩短、全局目标层重算、跨界杆件与独立架体碰撞、独立手算及平地 1.3 回归。`npm run audit:geometry` 通过 642 个几何案例和 504 次变换。`npm run lint` 与 `npm run build` 通过。三维按需加载的构建产物约 992 kB，Vite 提示分包体积，Android 实机性能待后续验证。

运行 `scripts/site-browser.mjs` 可重现 11 组网页检查，并在临时目录生成 `report.json`、桌面和平板绘图截图，以及走廊三维、四边尺寸和拖动对齐截图。平板验收使用浏览器模拟触摸。
