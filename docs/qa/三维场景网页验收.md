# 三维场景网页验收

2026-11-03 · `codex/site-elevation` · 独立架算网页。固定输入和手算表见[三维房屋与分段测算方案](../三维房屋与分段测算方案.md)。

| 环境 | 已验收的结果 |
| --- | --- |
| Chrome 桌面 1440 × 900 | 拖出体块、调高、选屋顶、画架段和保存重开。四条辅助边转为叠放体块，可撤销和重做。正面与花园可在同一三维场景检查，房屋可单独隐藏。 |
| 桌面材料表和导出 | 屋顶单跨 CSV 的定尺钢管、十字扣、底座和钢笆数量与手算一致，改成 3 层后对接扣为 4 个。正面与花园的 CSV 为 294 个十字扣、64 片钢笆、9 根底座、41.40 m²，0.7 项目同步保留测算结果。 |
| 错误定位和草图 | 窄顶面、跨台阶、扫地杆冲突、穿屋和独立架段重叠均能定位，材料 CSV 被拦截。窄顶面还能保存草图，修正后可再次查看材料。 |
| 标高、叠放和存档 | 恰好落在全局层标高时取下一层。父体块改高后撤销及保存重开均保留预期层数和标高。平地旧图读档后可导出 OA 0.6，平地闭环周长为 14.40 m。 |
| 左侧居中走廊 | 画布四边显示尺寸，走廊段 4 层，其余 5 层，四段顶层同为 9.40 m。可旋转检查三维架体并导出 CSV。拖动时显示居中对齐线，松手后可撤销，关闭吸附可自由移动。选中顶面后仍可在内部画子体块，也可拖顶面边框移动。 |
| Chrome 模拟触摸 1152 × 680 和 720 × 1110 | 单指画线和拖体块，双指取消未提交的笔画或移动。绘图、三维检查和材料表通过横竖屏视口检查。 |

`npm test` 通过 130 项，其中包含走廊前左转角、矩形吸附、独立手算、毫米边界、底座翼缘悬空、高差场景平移及旋转、平地 1.3 回归。`npm run audit:geometry` 通过 642 个几何案例和 504 次变换。`npm run lint` 与 `npm run build` 通过。三维按需加载的构建产物约 992 kB，Vite 提示分包体积，Android 实机性能待后续验证。

运行 `scripts/site-browser.mjs` 可重现 11 组网页检查，并在临时目录生成 `report.json`、桌面和平板绘图截图，以及走廊三维、四边尺寸和拖动对齐截图。平板验收使用浏览器模拟触摸。
