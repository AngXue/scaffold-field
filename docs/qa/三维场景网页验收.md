## 复测方法

在第一个终端运行 `npm run dev -- --host 127.0.0.1 --port 5182`。在第二个终端用已配置 Playwright 和 Chrome 的环境运行 `node scripts/site-browser.mjs`。需要指定路径时使用 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH`，可用 `SITE_URL` 和 `SITE_QA_OUTPUT` 指定地址及报告目录。

脚本以隔离的浏览器存储运行 11 组网页检查，输出 `report.json`、桌面和平板绘图截图，以及走廊三维、四边尺寸和拖动对齐截图。平板验收使用浏览器模拟触摸。Android 1.3 真机结果见[历史验收](1.3-平板测试.md)。
