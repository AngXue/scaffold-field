# 规则验收矩阵

`fixtures/rules/acceptance-matrix.json` 将批准方案的T01–T15与8组组合K01–K08绑定到现有测试的**完整文件名、断言标题和次数**。期望数量及坐标仍来自各测试里的固定手算和业务断言；清单不从计算结果反推期望，也不在运行时刷新。

## 执行

```bash
# 执行全部测试，逐项核查23行；允许网页证据暂缺，但明确保留T14待办
npm run test:rules -- --domain-only

# 对生产网页运行真实交互与导出检查
PLAYWRIGHT_MODULE=/path/to/@playwright/test/index.mjs \
  SITE_URL=http://127.0.0.1:5183 \
  SITE_QA_OUTPUT=/tmp/scaffold-rule-matrix-browser \
  node scripts/site-browser.mjs

# 复核同一版本的测试原始记录，加上网页证据；缺任一项非零退出
npm run test:rules -- --check --browser-report=/tmp/scaffold-rule-matrix-browser/report.json
npm run audit:rules
```

默认`npm run test:rules`会重跑测试且要求网页证据完整；`--check`仅重审已经保存的原始测试断言。产物在`artifacts/rule-migration/acceptance*.json`，不提交生成结果来代替可重复执行。

## 判定边界

- 必须含全部15个T项及8个K项，规则集合与45项正式目录相同。缺行、重复行、未知规则、空断言、同一断言重复登记均失败。
- 从Vitest实际逐条断言检查结果、名称和执行次数。整轮失败、单项失败、跳过、todo、缺文件或伪造汇总数量均失败；不能只检查测试文件存在。
- 证据绑定计算实现版本和验证源码摘要。后者包含src、scripts、固定输入、锁文件、相关构建配置及CI流程；修改代码、断言或输入后旧证据失效。启动新一轮之前先清掉旧的通过记录，新运行失败不得留下同版本旧通过结果。
- 网页脚本保留原11组操作：实际绘制、保存／重开、0.7／0.6、CSV、阻断后恢复和两种平板尺寸触摸。最后从实际加载页面下载诊断，核对其中计算版本与磁盘实现一致；运行前后验证源码不得改变。
- 计算测试通过不等于网页通过。缺少当前网页证据时，矩阵返回`domainAccepted: true`但`accepted: false`，T14明确待办。`audit:rules`重新读取原始记录和当前摘要，不信任`acceptance.json`中的通过文字。
- 本矩阵证明列出的业务回归及组合测试已执行，其中全局S0–S9已有当前追踪与故障合同，回退演练另有真实浏览器证据。矩阵不能替代尚未完成的全部中间实体身份／谱系及最终切换；完整审计仍保留这些独立门槛。

## 持续集成

`.github/workflows/rules.yml`在专用开发分支、main推送及PR执行：全部断言与矩阵、lint、生产构建、冻结旧版对照、几何审计、生产浏览器流程，再完成23行矩阵复核。旧引擎仍来自固定提交，因此完整获取Git历史；浏览器工具固定版本并隔离安装，不改变应用依赖或锁文件。

CI上传原始结果和网页截图供定位。性能测试继续按同机独立采样，不把CI共享机器上的耗时冒充已批准的本机性能证据。安卓真机仍不在本轮范围；桌面触摸模拟不作为APK验收。

第二十三批新增6个阶段构造合同，固定矩阵共引用190次断言；含多路径／多架体共同推进、实际立杆组装先于局部防护、失败后不能恢复以及禁止回退／重复阶段。该追踪范围明确不包括尚待迁移的P05全局跨标高连接。

第二十四批新增7个全局阶段／跨标高交接断言，固定矩阵共引用210次断言；完整26图验证全局非递减阶段，普通路径和诊断路径均注入倒退，并验证失败不可伪成功。全局阶段验收已独立绑定这些实际结果，完整内部实体谱系仍为单独待办。

新增构造身份合同覆盖内部需求与真实S4管组的关联、独立路径顺序、来源隔离、数值精度和显示映射失败；完整中间谱系验收仍单独待办。

第二十七批将真实合并／共柱／裁剪／删除来源及共享祖先快照列入T15，将第1段三处上层栏杆的中间替换关系列入T11；共210次登记断言。钢笆、底座及组管定位的完整中间身份仍由后续迁移补齐。
