## 4. 对照什么，怎样判定相同

比较前只规范化非业务差异：对象遍历顺序、临时 ID、诊断耗时、日志顺序。不能抹去几何、来源、规格、问题严重程度或真实连接差异。

| 层面 | 比较内容 | 精度与失败条件 |
| --- | --- | --- |
| 输入 | 原始场景、已恢复参数、人工增量、来源段数 | 原输入深比较不变；默认迁移依据固定适配规则 |
| 场景事实 | 父子关系、底／顶标高、真实轮廓、落脚段及来源区间、全局层号 | 标高和业务边界按毫米；层数／面 ID 精确相同 |
| 站位 | 两排柱脚、角柱、底座及每个跨距 | 按毫米比较几何多重集和支承关系；数量一样但位置不同仍失败 |
| 逻辑实体 | 类型、角色、起终点、连接点、全局层、来源集合、合并／拆分区间 | 几何及真实拓扑相等；旧版本缺完整 origins 的部分通过原始输入和明确谱系不变量补验 |
| 物理标准管 | 每段实长、规格、端点、接头位置、立柱禁用规格及错缝 | 规格和数量精确；管段坐标／连接按毫米；不因总长一致放过规格替换 |
| 钢笆 | 片数、实际 coverage 并集、分层覆盖、孔洞、面积 | 片数精确；覆盖内部计算精度保持现行；汇总面积按现有输出位数精确比较，几何残差另报 |
| 防护 | 每个所需标高的可通行区／临边、钢管覆盖区间、端封口、承托节点 | 检查真实定尺管连续，而不仅是 member 数或状态标签；无法避免的余量按已确认例外验收 |
| 扣件 | 成员对、类别、标高、位置／轴线、对接关系、数量 | 真实连接集合与数量一致；不能让两个错误抵消后总数相等 |
| 问题与未知值 | issue code、blocking、对应源段／体块，warning 类别，null/-- | 中文段号可随显示排序映射；缺失、降级或升级严重程度均失败 |
| 材料及导出 | 各规格、计算值、手工 delta、最终显示值、包数、CSV、OA 判定 | 精确相同；未知不转零；人工增量不进入实体图 |
| 规则解释 | 同一实体的规则链、变更区间及例外来源 | 数值等价外，还须解释链完整；trace 开关不得改变计算结果 |

对照若失败，报告最早出现差异的阶段和该阶段的输入摘要；保留前后产物供复现。先判断是错误、浮点比较策略错误还是新的业务差异，不能一键更新全部快照。变换测试对旋转／平移做逆变换后比较，排序不作为物理归属。

## 6. 必须新增的框架合同测试

M1 起新增，不混同当前已有覆盖：

1. 业务规则 ID 与执行步骤 ID 分别唯一、版本合法、draft/retired 不运行；步骤引用有效规则，缺依赖、循环依赖、跨阶段倒序在注册时失败。
2. 同一只读输入顺序可交换的规则给出同一规范化结果；业务依赖明确的规则不可乱序执行。
3. 非法提案类型、越权字段、过期输入版本、悬空实体引用均不能提交；输入冻结测试能发现嵌套突变。
4. 两规则同字段同结果可去重；不同结果无明确例外关系时报冲突；显式例外仅在谓词满足时生效，不能跨对象扩散。
5. 规则不适用时保留原因；失败阶段不发布半份材料，重复运行不追加第二套实体／扣件。
6. 合并、拆分、局部裁除后保留所有来源和剩余用途；桥接包围区快照不会被合并长杆修改。
7. 每个材料贡献来自可追溯实体；同一实体贡献唯一；未知数量与0区分；人工delta不写回几何。
8. 同输入／版本输出确定，详细 trace 开关不改变几何或数量；缓存开启／关闭完全等价。
9. 规则版本／实现变化使旧缓存失效；全局高度、库存、排距依赖传播正确；相机变化不重新计算。
10. Worker 若后续启用：结果带输入修订，旧任务不能覆盖新图；取消不导致半成品保存。

这些测试发现的是运行器和合同缺陷；它们不能自动决定未确认的施工构造。业务冲突须回到用户确认流程，不靠调大优先级或放宽断言通过。

## 8. 性能与平板计划

先做无缓存、详细 trace 关闭的配对测量。固定机器／Node 或浏览器、锁文件及输入，旧新交替运行，预热后至少100次，报告 p50/p95、峰值内存／分配、几何规模及环境；旧新不能与测试、构建同时争抢资源。平台间不直接比较绝对耗时。

最初建议预算为p50≤旧版1.10倍、p95≤1.20倍、峰值内存≤1.25倍。用户于2026-11-13明确允许性能稍许下降，实施采用有界更新：旧版p50不足1ms的小图，p50可额外增加0.25ms、p95可增加0.50ms；其他场景p50≤旧版1.20倍、p95≤1.25倍；峰值内存≤1.25倍保持。小图增加预热和每样本批量次数，仍以100个配对样本报告。超出更新门槛仍须定位并修复，不凭主观感受宣称达标。

规模至少包括：屋顶单跨、走廊、14段双屋、50／200段正交组合及多标高场景。大场景输入应可复用，先证明其自身无意外重叠，不用非法草图较早退出的耗时代表正常测算性能。

- Web：确认新增规则信息不占用画布；仍复用现有对象面板、问题定位、材料和导出组件。保留单次提交测算、撤销重做、独立层、三维拾取／隐藏／相机状态。
- 平板尺寸：1152×680、720×1110 模拟触摸复测；第二指取消笔画、平移缩放、输入框和横向溢出检查保留。
- 安卓后续：真机同图比较端到端耗时、峰值内存、连续编辑、离线启动、软键盘和导出；设备型号／WebView版本入报告。未安排 APK 阶段时明确记为未验收，不能用桌面触摸模拟替代。
- 若大图计算影响主线程，单独实施 Worker；移入前后同一纯引擎对照，验收结果修订号与取消机制。不能把线程迁移作为掩盖规则执行次数失控的手段。
