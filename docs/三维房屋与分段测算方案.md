# 三维房屋与分段测算

基于独立架算 1.3 的 `9c1217e`，在 `codex/site-elevation` 开发。OA 集成的是自己的固定 1.3 副本（OA 提交 `0d930bf`）；本轮交付独立网页，暂不制作 APK 或升级 OA。

## 现场操作

1. 打开「三维绘图」，选「房屋笔 → 矩形」，在俯视画布拖框。矩形的四边外侧显示尺寸。鼠标或单指可拖动体块，靠近其他体块或线段的边缘、中点时显示虚线并自动对齐，其余位置按 0.10 m 网格吸附。磁铁按钮可切换吸附。也可切到「辅助线」自由画线，点选四条闭合矩形边转为体块。新体块默认高 3 m，选中后可修改尺寸。要叠放，先选择下方体块的顶面，在顶面内拖框。拖动当前顶面的边框可移动它。
2. 选「脚手架笔」，默认从最低地面起算。沿任一矩形边拖一笔即可贴墙，画布会预览离墙侧的双排架体；沿途跨越可完整承托双排的低体块时，用不同颜色预览地面和顶面。松手后自动分段测算，侧栏列出每段落脚标高、实际层数及接通标高。可整笔修改目标全局层、长度，或拖动端点。要手动限定在一个顶面，使用落脚面列表、画布选面按钮，或在浏览模式点选顶面。
3. 「浏览」和「三维检查」可旋转查看房屋与架体，也能单独关闭房屋图层。对象面板显示落脚、首层和顶层标高；点击复核项定位到架段或体块。项目保存、历史、默认示例及 JSON 保留整个场景。「对象与测算 → 验收 Demo」可载入固定项目，载入前会确认是否替换当前画布。

桌面可用鼠标拖线、滚轮缩放、Shift 拖动或平移工具移动视图。平板沿用同一套笔、选面、参数和错误定位。短按选中，单指绘图或拖端点，双指平移与缩放。第二指按下时取消未提交的笔画，浏览模式用于旋转。横屏用侧栏，竖屏用可收起、可独立滚动的底栏，撤销键靠近画布。小顶面或被遮挡的顶面可从列表选取。输入在确认或离开编辑框时提交，画线只在松手时测算。后续 Android 实现根据软键盘遮挡范围收缩参数区，将当前数值框滚动到可见位置，并验收系统安全区、安装包和真机性能。

## 标高、校验和计量

- 场景使用米。最低地面为 0；顶面标高是父顶面（或地面）加体块高度。叠放的矩形必须完整落在父顶面且体块间不能实体相交。删除有依赖的体块前，先换面或移除相关对象。平移体块只改其坐标，原架段位置不自动改变，便于检查实际柱脚。
- 设落脚面毫米标高为 `B`，步距毫米值为 `H`，全局首层号为 `floor(B/H)+1`。逐段取连续指定层数。默认目标是全局第 5 层。新段默认齐顶，落脚面已到达或高过默认目标时填 1 层并提示。编辑体块或默认目标后保留已填层数。扫地杆、槽钢、立杆下端按各自落脚面计算。铺板间隔按该段的本地层序计。
- 先按落脚面、层数与连通性分组，同组沿用原有转角和定尺规则。自动笔画的高差交界只接通双方共有的全局层，纵向杆、外侧防护及该层钢笆按接通后的实体出量。手动指定的独立架段仍按落脚面分别估算。立杆的定尺仍禁用 5 m 钢管。
- 检查绘制线、实际两排柱脚与槽钢翼缘是否完整落在可用面内。同时检查定尺管和铺板穿屋、独立架段实体重叠及扫地杆冲突。几何碰撞采用保守的毫米容差，复核项可定位。新架段长度下限为 0.10 m，带场景的交点拆出更短的子段时须修正端点。落脚面丢失时提示重新选面。阻止出量时仍可保存和导出 0.7 草图，CSV、打印、OA 兼容导出及草图中的材料结果停用。结果是材料估算，屋面承载和高差连接构造需另行复核。
- 本机项目、历史、默认示例用独立 0.7 存档键，读取时可回退到旧键。旧图保留平面坐标和层数，全落在地面；平地延用旧图的厘米计量精度，带场景时计算水平坐标和层高使用毫米精度。无体块、辅助线、异高或异层的平地项目可另导出 OA 兼容 0.6。

## 验证方法

运行 `npm test`、`npm run audit:geometry`、`npm run lint`、`npm run build`。启动 `npm run dev -- --host 127.0.0.1 --port 5182` 后，用环境中的 Playwright 和 Chrome 运行 `node scripts/site-browser.mjs`。可用 `PLAYWRIGHT_MODULE` 指定模块入口、`CHROME_PATH` 指定 Chrome、`SITE_QA_OUTPUT` 指定截图与报告目录。浏览器脚本使用隔离存储，涵盖桌面以及 1152×680、720×1110 的模拟触摸视口。
