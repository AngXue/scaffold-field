# 冻结计算对照输入

基线为 `803ba541f059b4e8133d1887512669743d6dcb03`，包含 2026-11-12 沿墙退让修复。

`manifest.json` 固定旧源码归档、每个输入和旧版完整输出的 SHA-256。`npm run test:parity` 每次从该 Git 提交提取独立源码，在临时目录重放旧版，再与工作区新版逐字段比较；执行后删除仅由本次创建的临时目录。不会调用当前源码来代替旧版，也不会自动刷新基线。

输入覆盖内置 13 个 Demo、用户原始沿墙图及三类场景的独立层数、两道栏杆、90°旋转组合，共 23 项。输出摘要是旧程序结果，不代替独立手算；手算继续由 `site.test.ts` 中屋顶单跨与正面花园测试验证。比较保留现有 JSON 导出中的全部字段，包括构件坐标、杆件归属、扣件连接、规格、片框／覆盖、问题严重程度与材料。尚未新增谱系字段，因此当前按完整 JSON 等价比较；未来新增非业务诊断字段时须明确列出比较策略，不可任意删除字段使其通过。

错误时将字段分类及新旧完整结果写到 `artifacts/rule-migration/` 并非零退出。该目录不入库。需要具有基线提交的 Git 历史；不依赖网络或未保存的用户项目。
